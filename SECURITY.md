# Reporting a vulnerability

If you find something in this plugin that could leak data, send posts somewhere they should not go, or break the Plugin Hub rules, report it privately at https://github.com/slay-clan/slay-clan/security/advisories/new (the **Report a vulnerability** button under the Security tab), not in a public issue. Say what you found and how to reproduce it. A maintainer confirms the report within 7 days in the private advisory thread and agrees on a disclosure date with you.

Everything the plugin sends, and where, is listed in [docs/config.md](docs/config.md).
