# Reporting a security problem

If you find something in this plugin that could leak data, send posts somewhere they should not go, or break the Plugin Hub rules, report it privately through GitHub's **Report a vulnerability** button under the Security tab, not in a public issue. Say what you found and how to reproduce it; a clan staff member answers in the plugin's dev channel on Discord.

Everything the plugin sends, and where, is listed in [docs/config.md](docs/config.md).
